## Weather App

## About The Project
A simple and visually appealing weather application that fetches and displays the current weather for a given location. This project uses the OpenWeatherMap API to fetch weather data and displays it with a vibrant, gradient-based user interface.

## Features
- Real-time weather data fetching using the OpenWeatherMap API
- User-friendly interface with a dynamic gradient background
- Displays temperature, weather description, humidity, and wind speed
- Error handling for invalid or non-existent city names
- Visually appealing design with hover effects and animations

## Technologies Used
- HTML
- CSS
- JavaScript
- OpenWeatherMap API

## Usage
You can view the weather app by opening the index.html file in your web browser. Simply double-click the index.html file, or use a live server extension if you're using a code editor like VSCode.

1. Enter the name of a city in the input box.
2. Click the search button to fetch and display the current weather for the entered location.
3. If the city is found, the weather information will be displayed. If not, an error message will appear.
